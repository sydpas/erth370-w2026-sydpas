## General overview ##
This repository is for my paper that troubleshoots electrical resistivity tomography (ERT) data collected in June 2018 on the northeast face of Sulphur Mountain, Banff National Park, Alberta, where steep terrain and dense vegetation present surveying challenges. Finite element analysis is used to compute cumulative sensitivity, resolution, and coverage models using the Jacobian matrix, providing a framework for assessing inversion reliability independent of resistivity values. The results show that while sensitivity is high, resolution remains low for many cases, and thus the inverted resistivity values are poorly constrained. This study demonstrates that quantifying data reliability through sensitivity and resolution analysis is as critical as the inversion itself, particularly in challenging field environments where data quality cannot be assumed.
